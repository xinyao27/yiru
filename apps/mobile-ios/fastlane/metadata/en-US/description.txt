Yiru is a workspace for running coding agents in parallel.

Pair the app with Yiru Desktop to keep agent sessions, isolated Git worktrees, terminals, files, diffs, pull requests, and notifications together on your iPhone or iPad.

Use Yiru Mobile to:

- Open and switch between workspaces and agent sessions.
- Read and interact with persistent terminals, native chat, files, and browser previews.
- Review diffs, stage changes, commit work, and manage pull requests.
- Resume agent history and inspect activity and provider usage.
- Receive desktop notifications and open the relevant workspace directly.
- Add widgets for provider usage, token usage, and running workspace status.

Yiru does not provide or sell agent-provider accounts. Authentication, model access, and usage limits remain under the control of each provider configured on your paired desktop.
